# Contributing to Nylorun Harness

Thanks for contributing. The public package lives in [`harness/`](./harness) as [`@nylorun/harness`](./harness).

## Development workflow

Use a supported Node.js release (22.14, 24, or 26 or later), then run:

```sh
cd harness
npm ci
npm run check
```

Keep changes focused, include tests for behavioral changes, and update the package README, reference documentation, and changelog when the public API or observable behavior changes. Open a pull request using the provided template and include a concise compatibility and release note.
