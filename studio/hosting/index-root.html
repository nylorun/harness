Hosted Studio

Hey — welcome to Nylorun Studio

Waiting for a local Runtime. Run Studio from your project, then open the URL it prints.

Chrome may block local network access to your loopback Runtime by default.

Open Site information in the URL bar and allow Local network access for local.nylorun.studio. Chrome only for V1.

Connect from your project

  1. In your agent project, start the Runtime and Studio: 
    npx nylorun dev
    or attach Studio alone with 
    npx nylorun studio
  2. Open the Studio on … URL from the terminal. It includes a one-time pairing token in the fragment.
  3. When Chrome asks, allow local network access so this tab can reach http://127.0.0.1 on your machine.
